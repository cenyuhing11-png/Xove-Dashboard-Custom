# 进程状态胶囊

- 列表状态沿用 `po-status` / 原状态颜色，增加点击及 Enter/Space 操作；没有新增 CSS。
- 使用 Obsidian 自带的主题化 Menu，菜单位于胶囊旁；五项为计划中、进行中、暂停、已完成、归档。
- 名称仍打开完整详情，任务进度仍打开 compact preview，互不触发。
- 学习写回学习主题 Markdown；项目写回正式项目 Markdown。只改顶层状态属性，不修改其他 Properties、正文、任务 checkbox 或 data.json。
- 归档只是状态值，不移动或删除文件。

## 安全写入

从最新 Markdown 读取类型、项目身份、状态和 Embedded Task 未完成数，沿用 Obsidian YAML 解析。
非完成状态切为已完成且仍有任务时，复用 ConfirmModal：`还有 X 项任务未完成，仍标记为已完成吗？`，取消 / 仍然完成。
取消、Esc 和外部关闭均不写入；同一文件确认中不能开始第二次状态操作。
最终写入使用 `vault.process`，重查来源文件身份、状态与确认的未完成数。
并发的无关正文修改保留；状态/任务数变化、文件移动替换或不明确的 YAML 则拒绝写入，提示重新操作。
常规未加引号/加引号状态、行内注释、BOM 和 CRLF 保持；锚点/多行状态等非普通标量不会被强行重新格式化。

## 刷新与验证
