# 进程导航与快速任务预览 v1

本轮只扩展导航与任务交互，不改变 Process、项目、学习主题、Embedded Tasks 的存储格式，也不保存新的插件设置。

## 共享方向导航

首页、进程总览、收件箱均调用 `renderLifeCompass`，共享 `LIFE_COMPASS` 配置和现有 CSS。首页布局不变；其余两页将罗盘放在共享 Shell 与页面主体之间。方向名称打开现有人生方向详情，三个状态标签不可点击。收件箱的 OpportunityBoard 未修改。

进程侧栏用同一方向配置生成分组，点击只筛选当前 Board，不打开详情。方向、类型、状态取交集；改变任意一项保留另外两项。“全部进程”只清空方向。

侧栏计数采用全部进程源：总项显示进程总数；各方向显示 `学X · 项Y`，分别统计学习主题进程与正式项目进程，不统计资源或任务。计数不随类型、状态筛选变化；空方向保留 `学0 · 项0`。

## 日期与任务

列表日期按当前本地年份显示：同年 `MM.DD`，其他年 `YYYY.MM.DD`；完整中文日期放在 title。排序仍使用原 ISO 日期，不将纯日期解析为 UTC 时间。

列表和看板复用原按钮、计数样式显示任务胶囊。有任务显示完成数 / 总数；零任务显示禁用的“暂无任务”。名称和卡片主体继续进入各自学习或项目详情；胶囊阻止点击、键盘事件冒泡，只打开共享 `ProcessTasksModal`。

快速框直接读取 EmbeddedTaskStore 中当前来源笔记对应的“学习任务”或“项目任务”标题。待完成展开、已完成默认折叠；正文内部滚动，底部入口保持可见。勾选继续调用原 Store 写回原 Markdown；Store 通知同步更新分组和 Board 胶囊。任务文字打开来源笔记；底部打开现有完整详情。不复制任务、不创建独立任务文件、不编辑 Properties 或日期。

甘特图和日历继续使用进程级开始/截止日期与原详情路由，不把任务单日日期接入时间轴。它们复用的底部表格也使用相同任务胶囊。

## 快速预览 UI 收口

`30cfc9b` 首次引入 `ProcessTasksModal` 时，沿用了默认 Modal 宽度与 80vh 内容上限，并把更新日志的 `ad-update-block` 用作任务分组。标题、两行说明、卡片 padding 和 footer margin 叠加，导致短列表也像详情页。

对比 upstream 的 ConfirmModal、TaskModal、`.ad-propmenu` 和 `.po-check` 后，保留 Obsidian Modal 的焦点、Esc、外部关闭机制，采用 compact modal；不抽取绑定在 Dashboard 编辑菜单上的定位/关闭逻辑，避免扩大本轮纯视觉范围。

- 外壳复用 `.ad-propmenu` 的边框、圆角和背景，宽 400px，最大高 480px；小窗口分别限制为视口宽减 24px、高减 32px。
- 标题与一行“类型 · 任务进度”替代松散的三行信息；分组改为 section/details 和细分隔线，不再使用更新日志卡片。
- 保持 `renderEmbeddedRows` 和所有任务读写回调不变，仅在快速框内部为原生 checkbox 应用 ProjectBoard 的 `.po-check` 圆形视觉。浅色中性黑，深色使用原蓝色 accent，不依赖 Obsidian 默认紫色。
- footer 复用 `.po-back-btn`，作为透明背景的小型文字操作；关闭按钮沿用原生控件并缩紧尺寸。
- 原 428 项测试继续通过，新增 6 项纯视觉结构回归，总计 434 项；没有修改进程详情、Store、任务格式、模型或设置。
